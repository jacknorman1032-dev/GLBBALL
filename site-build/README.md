## How it's built
- `site-build/template.html` — the page. Data is injected at `/*__DATA__*/`.
- `site-build/build.py` — merges research JSON + overrides + player updates + game logs + corrections into `greater-lansing-hoops.html`. School list is `BASE`.
- `site-build/overrides.json` — hand corrections (colors, nicknames), extra players (`add_players`: Trevor Manuel and Clyde McKinney Jr. for Everett, Paul Crosby for Holt, Drew Valentine for Sexton, Alex Gauna, Sean Romsek). Thomas (T.J.) Jackson was added straight to research/east_lansing_region.json, and `tournament_summary` (district/regional history) for Portland and Charlotte.
- `site-build/player_updates.json` (added Oct 28, 2026) — player facts Jack confirms (grad years so far), keyed by school id and exact player name. build.py applies them after research and overrides, clears the "approx" flag when a grad year is set, and stops with an error if a name no longer matches exactly one player. Put new player confirmations here rather than editing research/*.json. Copy it next to build.py.
- `research/*.json` — program histories gathered Oct 28, 2026 (every fact has a source URL). build.py reads them from a `research/` folder next to it.
- `honors/bcam_allstate.json` — BCAM all-state picks for the 18 schools (copy next to build.py as `honors_bcam.json`). Feeds the Honors tab, each school page's "All-state honors" table, and BCAM chips on player cards (matched by name, ignoring Jr./II and nicknames in parentheses).
- `honors/bcam_statewide_raw.json` (every BCAM entry statewide, ~600 KB) was removed from the project Oct 28, 2026 to stay under the 2 MB project limit; Jack has a downloaded copy. Re-add it (or re-run parse_bcam.py on the PDFs) before adding schools beyond our 18.
- `site-build/parse_bcam.py` — parser for the BCAM PDFs (run on per-column text from pdfplumber, page split at the middle).

## Rules (match the ELHS spreadsheet)

## Decisions
- Champion rating: finish points are scaled by class (Oct 30, 2026). Class A or Division 1 gets 100%, B or D2 90%, C or D3 80%, D or D4 70%. Final Four, regional and district finishes have no class in the data, so they get 100%. The weights are the `DIVW` table in template.html.
