# Uniforms section (added Oct 30, 2026)

School pages can show a "Uniforms" box with labeled drawings (Home, Away, and Alternate where a school has one), placed right after Banners.

## Rules
- Drawings: `site-build/uniforms/<file>.svg`, flat front view (jersey + shorts, black outline, viewBox 0 0 160 285), generic number 0, no maker logos (Nike, Ninato, MB, Under Armour).
- Lettering uses system fonts or hand-drawn shapes, never web fonts (the site shows each drawing as an image). Place arched letters one by one (no textPath). Script and custom block lettering are drawn as shapes.
- Embedded logos are PNGs shrunk to about 56-64 px and palette-quantized (keeps each SVG under ~10 KB; the project has a 2 MB cap).
- To add a school: drop its SVGs in `uniforms/`, add an entry to `UNIFORMS` in add_uniforms.py, re-run, publish the SVGs with the page via Artifact `files` at `uniforms/<file>.svg`.
- After a rebuild, run `python3 -I add_uniforms.py greater-lansing-hoops.html` (template.html does not include this yet).
